# Dataset Information

This project uses multiple Excel files representing different aspects of a SaaS subscription business.

## Files Included

* **ravenstack_accounts.xlsx** – Customer account information.
* **ravenstack_subscriptions.xlsx** – Subscription details and customer lifetime data.
* **ravenstack_churn_events.xlsx** – Customer churn events, churn reasons, and refund amounts.
* **ravenstack_feature_usage.xlsx** – Product feature usage by customers.
* **ravenstack_support_tickets.xlsx** – Customer support interactions and ticket information.

These files were combined in Power BI using relationships to perform customer retention and churn analysis.
